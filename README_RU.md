# NOWA — этап 5: аудио- и видеозвонки (WebRTC)

Добавлена основа звонков между двумя авторизованными пользователями:
- кнопки голосового и видеозвонка в шапке чата;
- запрос микрофона/камеры;
- обмен WebRTC offer/answer и ICE-кандидатами через Socket.IO;
- входящий вызов: принять/отклонить;
- отключение микрофона и завершение звонка.

## Запуск
Используйте backend и клиент из этого архива. Установите зависимости в `server/` (`npm install`), настройте `.env` как в предыдущих этапах и запустите `npm start`. Разместите `client/` на HTTPS и пропишите в `client/index.html` публичный URL API вместо `http://localhost:3000`. Оба участника должны войти в NOWA, быть онлайн и открыть чат друг с другом.

## Проверка
1. Откройте NOWA в двух браузерах/профилях с разными аккаунтами.
2. Добавьте друг друга в контакты и откройте чат.
3. Нажмите трубку для аудио или значок видео.
4. На втором устройстве примите вызов и разрешите доступ к микрофону/камере.

## Важные ограничения
- Это WebRTC MVP. Используется публичный STUN-сервер для начального тестирования; в некоторых сетях звонок не соединится.
- Для надёжной работы через мобильные сети, NAT и корпоративные сети нужен собственный TURN-сервер (например, coturn) и его credentials в конфигурации `RTCPeerConnection`.
- Требуется HTTPS (кроме localhost) и разрешения ОС/браузера на микрофон и камеру.
- Нет групповых звонков, фонового звонка при закрытом приложении, записи звонков и push-сигнализации входящего вызова.
- Не проводился аудит безопасности. Не считайте эту сборку готовой для публичного релиза.
